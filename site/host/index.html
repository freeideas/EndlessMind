Keep a realm up

A realm is playable while someone referees it: a browser tab hosting it, or the host program running on a computer you control.

The host program needs only an outgoing internet connection, so a computer at home behind a router works. It also lets a realm keep its rules private, for example to have an AI model answer players, with the model's key staying on your computer.

Run it

  1. Install Deno, a program that runs JavaScript: brew install deno on macOS or Linux, winget install DenoLand.Deno on Windows.
  2. Get the code: git clone https://github.com/freeideas/EndlessMind.git, then cd EndlessMind.
  3. Start it with your realm's folder:
deno task host --server https://play.endlessmind.com --realm path/to/your-realm

It prints the realm's link. Each start publishes the folder's current files under the same key, so the link stays the same. The key is kept in keys/; back it up.

The details, including private rules and keeping it running after a restart, are in RUNNING.md.

Endless Mind™ is an open protocol, and nothing depends on this website or its helper servers. Source and docs: github.com/freeideas/EndlessMind.
