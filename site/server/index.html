Run a helper server

Helper servers let actors find each other, pass messages along, and keep copies of realm files. Anyone can run one, and a group of friends needs only one.

A helper server holds no game state and makes no rules. It sees who talks to whom, but moves and views are locked so that only the actor and the realm's referee can read them. Everything it keeps is signed or named by its fingerprint, so it cannot forge anything.

On your own computer

  1. Install Deno: brew install deno on macOS or Linux, winget install DenoLand.Deno on Windows.
  2. git clone https://github.com/freeideas/EndlessMind.git, then cd EndlessMind.
  3. deno task start. It prints the address to open in your browser.

For other devices and the internet

Browsers allow the key functions Endless Mind uses only on https addresses (or on localhost), and the server must be told the address it goes by, with --origin https://your.address. A quick tunnel, a private network, or a real server behind Caddy all work; RUNNING.md explains each.

Endless Mind™ is an open protocol, and nothing depends on this website or its helper servers. Source and docs: github.com/freeideas/EndlessMind.
