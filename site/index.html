Anything AI can make, open to anyone from a link.

Endless Mind connects games, places, shops and tools made with AI into one open network, the way the web connects websites. There is no company in the middle and no account to make.

Play

Open a realm's link in a portal (the program that gets you in). The one at play.endlessmind.com runs in your web browser. The first time, it makes you a character: a name and a look, held as a secret key in your browser that you take from realm to realm. Choose Save my keys to keep a copy.

Try one now: Lantern Maze, a chase game, or The Listening Well, where an AI answers your questions.

Create

You do not need to be a programmer, only an AI coding agent (a program such as Claude Code that writes code for you). Tell it what you want and point it at the guide. How to make something.

How it works, in short

  • Characters and realms are keys. Whoever holds a key controls it, on any device and any server.
  • Code that runs on your device is public and sandboxed, kept away from your files and the network.
  • Each realm makes its own rules and referees itself. When its rules are public, your portal checks the referee against them, so nobody has to trust whoever hosts.
  • Helper servers only pass messages along and keep files. Anyone can run one, and none is in charge.

Status: early. Expect rough edges and frequent changes.
