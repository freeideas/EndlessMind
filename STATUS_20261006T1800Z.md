## Built and tested on one computer

- **EntryPortal:** [site/EntryPortal/v0.1/index.html](site/EntryPortal/v0.1/index.html), one self-contained file; `site/EntryPortal/index.html` forwards to the newest version, and realms name that address. Shared code is copied in from `shared/` by `deno task portal` (chosen over hand-copying so the reviewed code and the tested code stay the same; a test fails if it is stale).
- **Realm library:** [realm/](realm/README.md), with Project Nayuki's QR encoder (MIT) vendored.
- **Example realm:** [examples/lantern-garden/](examples/lantern-garden/README.md).
- **Tests:** `deno task test` (units), `deno task browser` (two browsers through the whole loop, reading the QR codes off the screen).
- **Protocol additions** made while building, now in PROTOCOL.md: after countersigning, the realm sends the complete records back to the EntryPortal with `#sign=` and no `return` (keep only); `return` must match the origin signed in to; burn notices go to any join address; a plain visit to a join address may forward to the EntryPortal.
