# Contributing

Thank you for helping. Anyone may propose changes; how decisions about the protocol are made is described in "How the protocol changes" in [specs/PROTOCOL.md](specs/PROTOCOL.md). Working conventions for this repository are in [AGENTS.md](AGENTS.md).

## Licensing of contributions

By contributing, you agree that your contribution may be used under the same terms as the rest of this repository:

- code: your choice of the MIT license or the Apache License 2.0, as for everyone else;
- documents in `specs/`: dedicated to the public domain under CC0 1.0.

No contributor, including the project's founder, gets extra rights over anyone else's contributions, and nothing will ever need relicensing.

## Sign your commits (Developer Certificate of Origin)

Add a `Signed-off-by` line to each commit, which `git commit -s` does for you. It certifies that you wrote the change or otherwise have the right to submit it under these terms, as set out in the Developer Certificate of Origin, version 1.1 (https://developercertificate.org/).

## Security problems

If you find a way to forge signatures, impersonate a key, escape a sandbox, or otherwise break the protocol's guarantees, please report it privately to the maintainers first (open a GitHub security advisory on the repository), so a fix can be published before the problem is widely known.
